# Course Duration Calculator

A Python script that converts a given number of minutes into a user-friendly format of hours and minutes.

## Features
- **User Input:** Prompts the user to enter the total duration of a course in minutes.
- **Time Conversion:** Automatically calculates the exact hours and remaining minutes using floor division and modulo operations.
- **Formated Output:** Displays the final result in a clear, readable text format in the console.

## Technologies Used
- Python 3
